# Contributing

This is an **issues-only** support and binary-distribution repository. External users can report bugs, provide testing feedback, and request features through [GitHub Issues](https://github.com/joaojmendes/workspace-in-a-box/issues/new/choose).

Pull requests and direct repository changes are not accepted. The application and documentation are maintained by the repository owner, and external pull requests are closed automatically.

## Good bug reports include

- the exact package version;
- the affected webpart and widget;
- SharePoint or Teams host;
- browser and operating system;
- site manager or ordinary-user context;
- reproducible steps;
- expected and actual results;
- sanitized logs or screenshots.

Search for an existing issue before creating a new one. Keep one independently actionable problem per issue.

Do not include confidential or security-sensitive information. Follow [SECURITY.md](SECURITY.md) for vulnerability reporting.
